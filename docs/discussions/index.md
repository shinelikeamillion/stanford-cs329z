# 讨论与整理

这里放**学习过程中的问答、争论和整理**：一个主题一页，写清问题、各方观点、我的结论和还没验证的部分。和讲义页的分工是：讲义页忠于课件，讨论页记录我自己的判断。

新增讨论请复制仓库里的 `templates/discussion.md`，文件名用 `NNNN-slug.md`，并在下表和侧边栏登记。约定见仓库根目录的 `CONTRIBUTING.md`。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| `draft` | 刚起草，结论不可靠 |
| `open` | 问题还在讨论，有部分结论 |
| `resolved` | 已有稳定结论 |
