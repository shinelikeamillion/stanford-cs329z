# 讲义笔记总览

每一讲一页，文件名是 `lecture-NN.md`。**L01 是完整样板，L02 已完成**；其余各讲目前是占位页，只有标题、官方链接和官方阅读材料，之后按 `templates/lecture.md` 的八个部分逐讲补全。

## 每页的固定结构

1. **概览**：一句话总结、本讲结构、读完应该能回答的问题
2. **核心概念**：概念表
3. **详细笔记**：按课件顺序分节，覆盖整份课件，标出页码范围
4. **关键图示**：用 Mermaid 自行重画的示意图
5. **重点 / 易错点**
6. **讨论与思考题**
7. **延伸阅读与资源**
8. **与项目的联系**
